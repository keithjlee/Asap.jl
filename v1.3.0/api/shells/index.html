Shells, walls and diaphragms

Shell sections and elements, their kernels, surface loads, resultants and section cuts, the wall mesher, link elements and rigid diaphragms.

Asap.AbstractShellSection — Type
AbstractShellSection{T<:Real}

Supertype of all shell (surface) sections — the through-thickness description of a ShellElement.

Like AbstractSection for members, a shell section's entire contract with the analysis layer is a rigidity accessor interface: the thickness-integrated constitutive matrices a linear flat-shell stiffness consumes, plus mass per unit area. Kernels never read struct fields.

AccessorMeaningDimension
membrane_rigidityin-plane stress resultant per unit strain, N = A·ε (3×3)[force/length]
bending_rigiditymoment per unit curvature, M = D·κ (3×3)[force·length]
shear_rigiditytransverse shear per unit shear strain, Q = S·γ (2×2)[force/length]
drilling_rigiditypenalty tying the drilling rotation to the in-plane rotation of the displacement field[force/length]
areal_massmass per unit area[mass/length²]

Voigt ordering everywhere: (xx, yy, xy) with ENGINEERING shear strain γxy = ∂u/∂y + ∂v/∂x and twist κxy = ∂βx/∂y + ∂βy/∂x; transverse shear (xz, yz). Matrices are expressed in the element's local axes.

No membrane–bending coupling block (B in classical lamination theory) is carried: sections are symmetric through the thickness. Eccentric or layered sections are out of scope for linear 1.3.

Asap.ShellRigiditySection — Type
ShellRigiditySection{T} <: AbstractShellSection{T}

A shell section defined directly by its thickness-integrated rigidities — the shell analogue of RigiditySection. Use it for cracked or effective concrete stiffness, orthotropic or equivalent plates (ribbed, hollow-core, or composite decks), and optimization parameterizations.

Fields

  • A::SMatrix{3,3,T}: membrane rigidity N = A·ε [force/length]
  • D::SMatrix{3,3,T}: bending rigidity M = D·κ [force·length]
  • S::SMatrix{2,2,T}: transverse shear rigidity Q = S·γ [force/length]
  • γt::T: drilling penalty rigidity [force/length] (default: A[3,3], the in-plane shear rigidity, i.e. γ = G)
  • ρt::T: mass per unit area [mass/length²]

Constructors

ShellRigiditySection(A, D, S, ρt; γt = A[3,3])
ShellRigiditySection(sec::ShellSection; f11 = 1, f22 = 1, f12 = 1,
                     m11 = 1, m22 = 1, m12 = 1, v13 = 1, v23 = 1, mass = 1)

The second form applies stiffness modifiers (the property-modifier convention of common building-analysis software) to an isotropic section:

  • membrane: A[1,1]·f11, A[2,2]·f22, A[3,3]·f12, and the Poisson coupling A[1,2]·√(f11·f22) (keeps A positive definite);
  • bending: D[1,1]·m11, D[2,2]·m22, D[3,3]·m12, coupling ·√(m11·m22);
  • transverse shear: S[1,1]·v13, S[2,2]·v23;
  • the drilling penalty follows the modified in-plane shear rigidity;
  • mass scales the areal mass.

Direction 1 is the element's local x-axis. A cracked wall under ACI 318-19 Table 6.6.3.1.1(a), for instance, takes m11 = m22 = m12 = 0.35 (or 0.70 uncracked); which modifiers a code prescribes is the user's (or a design kernel's) decision, not Asap's.

Examples

julia> wall = ShellSection(Material(4.0e6, 0.15, 0.2), 8 / 12);

julia> cracked = ShellRigiditySection(wall; m11 = 0.35, m22 = 0.35, m12 = 0.35)

Asap.ShellSection — Type
ShellSection{T} <: AbstractShellSection{T}

A homogeneous, isotropic shell of uniform thickness — the standard section for concrete walls, slabs, and steel plate.

Rigidities are derived on demand from the material and thickness t (plane-stress Reissner–Mindlin plate theory):

  • membrane: A = t·Q, with Q = E/(1−ν²)·[1 ν 0; ν 1 0; 0 0 0] + G·e₃e₃ᵀ
  • bending: D = t³/12·Q
  • transverse shear: S = κ·G·t·I₂, shear correction κ = 5/6
  • drilling penalty: γ·t with γ = G (Hughes & Brezzi 1989; Ibrahimbegović, Taylor & Wilson 1990 — results are insensitive to γ over several orders of magnitude)

The in-plane shear term uses the material's stored G, which equals the isotropic value E/(2(1+ν)) whenever the material was built with Material(E, ρ, ν).

Fields

  • material::Material{T}: the shell material (E, G, ρ, ν)
  • t::T: thickness [length]

Examples

julia> concrete = Material(4.0e6, 0.15, 0.2);    # kip, ft: E in kip/ft²

julia> wall = ShellSection(concrete, 8 / 12)        # 8 in wall

For cracked/effective or orthotropic stiffness use ShellRigiditySection, including its stiffness-modifier constructor.

Asap.ShellElement — Type
ShellElement{T, N, S<:AbstractShellSection{T}} <: AbstractElement{T}

A flat shell (surface) element with N corner nodes — membrane action with a true drilling rotation plus plate bending — for walls, slabs, diaphragms and general shell surfaces. Mixes freely with frames and trusses in one Model; shared nodes connect them with full 6-DOF continuity (the drilling DOF lets an in-plane beam transfer moment into a wall).

N = 4 (quadrilateral) is implemented: the Ibrahimbegović–Taylor–Wilson drilling membrane combined with the MITC4 plate (see docs/shells/DERIVATION.md). The node count is a type parameter so elements of different shapes assemble in separate type-stable groups.

Fields

  • nodes::NTuple{N,Node{T}}: corner nodes, ordered counter-clockwise about the element's outward normal (right-hand rule); the normal sets the sign of the local z-axis, of out-of-plane loads, and of moment resultants
  • section::S: the shell section (ShellSection or ShellRigiditySection)
  • id::Symbol: user tag
  • index::Int: position in model.elements (assigned by process!)

Local axes

e₃ = normalized cross product of the diagonals; e₁ = edge node 1 → node 2 projected onto the element plane; e₂ = e₃ × e₁ (see shell_frame). Stress resultants are reported in these axes — order the nodes so edge 1 runs along the direction you want as "1" (the wall mesher does this consistently).

Constructors

ShellElement(nodes, section, id = :shell)   # nodes: tuple or vector of 4 Nodes

Examples

julia> wall = ShellSection(Material(4.0e6, 0.15, 0.2), 8 / 12);

julia> el = ShellElement((n1, n2, n3, n4), wall, :wall)

Asap.LinkElement — Type
LinkElement{T} <: AbstractElement{T}

A zero-length 2-node spring connecting two COINCIDENT nodes with six uncoupled stiffnesses in a chosen frame — the connection element for precast panel joints (horizontal/vertical joints of shear walls, bearing pads, dowel connections), base isolators, or any "these two parts are attached, but not rigidly" condition.

Element stiffness (global): [k −k; −k k] with k = blockdiag(Rᵀ·diag(kₜ)·R, Rᵀ·diag(kᵣ)·R), where R (rows = link axes) orients the springs. Zero length is enforced at process!: a spring between OFFSET nodes would need rigid arms for moment equilibrium; model those explicitly (a stiff FrameElement) if you need them.

Fields

  • nodeStart::Node{T}, nodeEnd::Node{T}: the two coincident nodes
  • k::SVector{6,T}: stiffnesses (k₁, k₂, k₃, kθ₁, kθ₂, kθ₃) along/about the link axes [force/length] and [force·length/rad]; 0 = released
  • R::SMatrix{3,3,T}: rows are the link axes in global coordinates (default: global X, Y, Z)
  • id::Symbol, index::Int

Constructors

LinkElement(n1, n2, k::AbstractVector; axes = I, id = :link)

Examples

julia> joint = LinkElement(top_of_lower_panel, bottom_of_upper_panel,
                           [1e6, 1e6, 5e6, 0, 0, 0]; id = :hjoint)   # shear + bearing, no moment

Asap.itw_membrane_stiffness — Method
itw_membrane_stiffness(xy, A, γt; enhanced = true) -> SMatrix{12,12}

Local membrane stiffness of the Ibrahimbegović–Taylor–Wilson drilling quad (D-type, ITW eq. 3.24) over the DOFs (u, v, ψ) of nodes 1…4.

  • xy: local in-plane node coordinates (counter-clockwise) [length]
  • A: membrane rigidity [force/length]
  • γt: drilling penalty rigidity [force/length]

K = K̂ + P: K̂ integrates [B G]ᵀA[B G] by 3×3 Gauss with internal modes statically condensed; P integrates the penalty γt·∫(skew∇u − ψ)² with a single point.

Internal modes: ITW's hierarchical bubble (1−ξ²)(1−η²), plus — when enhanced (the default) — two incompatible modes u ∝ 1−ξ², v ∝ 1−η² with Taylor–Beresford–Wilson (1976) derivatives (centre Jacobian, scaled by detJ₀/detJ, so the patch test still passes on distorted meshes). Allman's edge modes already span the NORMAL edge quadratics; these two add the complementary tangential ones, which the Poisson strain of in-plane bending needs: the enhanced element is exact in pure bending on rectangles (the published element is 2.6 % stiff at ν = 0.3) and more accurate on coarse wall meshes. enhanced = false reproduces the element as published. See docs/shells/DERIVATION.md §2.1 for the benchmark comparison.

Asap.shell_frame — Method
shell_frame(X1, X2, X3, X4) -> (R, xy, warp)

Local frame of a 4-node flat shell from its global node positions:

  • R::SMatrix{3,3}: rows are the local axes e₁, e₂, e₃ in global coordinates (v_local = R·v_global). The normal e₃ is the normalized cross product of the diagonals (well defined for warped quads); e₁ is edge 1 (node 1 → node 2) projected onto the mean plane; e₂ = e₃ × e₁.
  • xy::NTuple{4,SVector{2}}: in-plane local coordinates of the nodes relative to the centroid (warped nodes projected onto the mean plane) [length].
  • warp::T: largest out-of-plane offset of a node from the mean plane, divided by √(area) (dimensionless warping measure; 0 for a flat quad).

Asap.AreaLoad — Type
AreaLoad{T} <: ElementLoad{T}

A uniform surface traction on a ShellElement [force/length²] — pressure on a slab or wall, wind on a façade panel, superimposed dead load.

Lowered to CONSISTENT nodal loads from the element's own interpolation (including the work done on the drilling rotations by in-plane traction, and the condensed internal modes); see shell_load_vector.

Fields

  • element::AbstractElement{T}: the loaded shell element
  • q::SVector{3,T}: traction [force/length²], in global or local axes
  • frame::Symbol: :global (default) or :local (element axes e₁, e₂, e₃; a local q = (0, 0, p) is a pressure p along the element normal and follows the element's orientation)
  • id::Symbol, case::Symbol: tags

Constructors

AreaLoad(element, q::AbstractVector; frame = :global, id = :area, case = :LC1)
AreaLoad(element, p::Real; id = :area, case = :LC1)   # normal pressure along +e₃

Examples

julia> AreaLoad(slab, [0.0, 0.0, -0.1])        # 0.1 [force/length²] downward
julia> AreaLoad(facade, -0.03; case = :W)       # suction along −e₃

SelfWeight(element) also applies to shells: q = ρt·g·factor from the section's areal_mass.

Asap.section_cut — Method
section_cut(model, elements, cut_nodes; about = centroid(cut_nodes),
            axes = I, results = model.results) -> (F, M)

Resultant force F and moment M (about the point about) transmitted ACROSS a cut into the free body formed by elements, through the nodes cut_nodes that lie on the cut — the integrated "pier/spandrel" forces a wall design check consumes.

Computed from the elements' nodal forces (f = K·u + q̃) at the cut nodes, which makes it exact for equilibrium on any mesh: for a free body whose only other actions are known loads, F and M balance them to machine precision, independent of mesh refinement (no stress smoothing involved). Frame and truss members crossing the cut (e.g. boundary columns embedded in a wall) are included by listing them in elements.

  • elements: elements on ONE side of the cut (any mix of ShellElement, FrameElement, TrussElement)
  • cut_nodes: nodes on the cut line
  • about: moment reference point (default: centroid of cut_nodes)
  • axes: 3×3 matrix whose ROWS are the reporting directions (default: global); e.g. rows (wall length, wall thickness, vertical) give F = (V₂, V₃, P) and M = (M₂, M₃, T) for a pier
  • results: any LinearResults (a case, or a combined combination — element forces superpose)

Sign: F/M are the actions OF the rest of the structure ON elements.

Example

julia> below = filter(el -> centroid_z(el) < z_cut, wall_elements);

julia> cut = filter(n -> n.position[3] ≈ z_cut, wall_nodes);

julia> F, M = section_cut(model, below, cut)   # storey shear, axial, overturning

Asap.shell_resultants — Method
shell_resultants(model, el::ShellElement; at = (0.0, 0.0), results = model.results,
                 factors = nothing) -> NamedTuple

Stress resultants of a solved shell element at natural coordinates at = (ξ, η) ∈ [−1, 1]² (default: the element centre), in the element's local axes (shell_frame):

  • N = (Nxx, Nyy, Nxy) [force/length] — membrane forces, tension positive
  • M = (Mxx, Myy, Mxy) [force·length/length] — bending/twisting moments per unit width; positive Mxx puts the +e₃ face in tension along e₁
  • Q = (Qx, Qy) [force/length] — transverse shear forces
  • frame::SMatrix{3,3} — the local axes (rows e₁, e₂, e₃)

results/factors select which solution to read (e.g. a combination from combine with its case factors), exactly as for internal_forces: factors = Dict(case => factor) weights the element's own surface loads, which the membrane's condensed modes depend on. Element centres are the superconvergent sampling points of the bilinear fields; corner values are extrapolations — smooth them only deliberately.

Asap.edge_loads — Method
edge_loads(el::ShellElement, edge::Int, w::AbstractVector; case = :LC1) -> Vector{NodeLoad}

Consistent nodal loads of a uniform LINE traction w [force/length] (global vector) along edge edge (1…4; edge k joins nodes k → k+1) of a 4-node shell: forces w·l/2 at both ends plus — because the drilling membrane's edges deform quadratically with the end rotations — drilling moments ∓(w·n)·l²/12 about the element normal at the start/end node, where n is the edge's outward in-plane normal. Without the moments a uniform edge traction is not represented consistently (e.g. a uniform tension field would not be reproduced exactly).

Asap.mesh_wall — Method
mesh_wall(origin, along, up, length, height, section;
          openings = [], s_lines = [], z_lines = [], size = height / 4,
          reuse = Node[], fixity_bottom = :fixed, id = :wall) -> WallMesh

Mesh a planar rectangular wall with ShellElements on a structured grid.

  • origin: global position of the wall's bottom-left corner
  • along, up: unit in-plane directions (length, height); orthogonal
  • length, height [length]
  • section: the wall's AbstractShellSection
  • openings: rectangles (s₀, z₀, width, height) in wall coordinates (doors, windows); cells inside are removed and opening edges become grid lines, so piers and spandrels are meshed exactly
  • s_lines, z_lines: extra hard lines — storey levels, frame/column lines, load points — guaranteed to be grid lines
  • size: target element size [length]
  • reuse: existing nodes; a mesh node at the same position (to 1e-9 relative) REUSES it, which is how walls connect to each other (L/C/T cores share their corner lines) and to frames (beam/column nodes on the wall's grid lines)
  • fixity_bottom: support symbol for the bottom row (:fixed, :pinned, or :free to leave it unsupported); reused nodes keep their own fixity

The structured grid keeps every element rectangular — the regime where the membrane is exact in pure bending (see docs/shells/DERIVATION.md).

Asap.RigidDiaphragm — Type
RigidDiaphragm{T}

A rigid in-plane diaphragm: the in-plane translations and the rotation about the plane normal of every SLAVE node follow a MASTER node as a rigid body — the conventional floor model for building lateral analysis (a floor slab is far stiffer in its plane than the walls and frames it ties together). Out-of-plane translation and the two out-of-plane rotations of each slave stay independent, so floor bending, column axial forces and wall overturning are unaffected.

For a diaphragm normal to global axis a with in-plane axes (b, c) (Z: (X, Y); X: (Y, Z); Y: (Z, X)) and offsets r = x_slave − x_master:

u_b,s = u_b,m − θ_a,m · r_c
u_c,s = u_c,m + θ_a,m · r_b
θ_a,s = θ_a,m

Imposed exactly by transformation (u = C·û), not by penalty springs — see docs/shells/DERIVATION.md §5.

Fields

  • nodes::Vector{Node{T}}: slave nodes (the floor's nodes)
  • master::Node{T}: the node whose 3 in-plane DOFs carry the diaphragm; apply story forces and torsional moments here
  • axis::Int: global axis of the plane normal (1 = X, 2 = Y, 3 = Z)
  • id::Symbol

Constructor

RigidDiaphragm(nodes; master = nothing, axis = :Z, id = :diaphragm)

With master = nothing a master node is created at the slaves' centroid: its 3 in-plane DOFs free, its 3 out-of-plane DOFs fixed (it is a kinematic node, not a structural one). The model adds it to its node list.

Example

julia> floor2 = RigidDiaphragm(level2_nodes; id = :L2);

julia> model = Model(nodes, elements, [NodeForce(floor2.master, [Fx, 0, 0])];
                     diaphragms = [floor2])

Slave nodes must not be supported in the diaphragm's in-plane DOFs, and a node may belong to only one diaphragm. Gradients through the pure path treat the master–slave offsets as constant (frozen at the last solve!).

Asap.mitc4_plate_stiffness — Function
mitc4_plate_stiffness(xy, D, S) -> SMatrix{12,12}

Local MITC4 plate stiffness over the DOFs (w, θx, θy) of nodes 1…4 (Dvorkin & Bathe 1984; Bathe & Dvorkin 1985).

  • xy: local in-plane node coordinates (counter-clockwise) [length]
  • D: bending rigidity [force·length]
  • S: transverse shear rigidity [force/length]

Bending ∫Bbᵀ D Bb and assumed-strain transverse shear ∫Bsᵀ S Bs, both by 2×2 Gauss. The covariant transverse shear strains are tied at the four edge midpoints, which removes shear locking: the element is valid from thick (Reissner–Mindlin) to thin (Kirchhoff limit) plates.

shell_load_vector(section, X1, X2, X3, X4, q_global) -> (q̃_local, R)

The shell's fixed-end-force vector (Asap convention: Pf and the q in the force recovery f = K·u + q̃) for a uniform surface traction given in GLOBAL axes [force/length²]: the NEGATED consistent load, with the internal-mode load condensed onto the nodes, f̂ = fₐ − K_ab K_bb⁻¹ f_b. Local node-major 24-layout; R is the element frame (rows = local axes).

Asap.shell_consistent_load — Function
shell_consistent_load(xy, q) -> (f24, fb)

Consistent local nodal loads of a uniform surface traction q = (qx, qy, qz) [force/length²] in the element's local axes, from the element's own interpolation (3×3 Gauss):

  • membrane: ∫Nₐ q∥ on (u, v), and ∫dₐ·q∥ on the drilling DOF ψ (the Allman edge modes do work under in-plane load);
  • plate: ∫Nₐ qz on w (MITC4 rotations are independent fields — a uniform pressure does no work on them);
  • fb: the load on the internal modes (bubble ∫NB q∥; the incompatible modes are strain enhancements and carry none), used for condensation.

Returns f24 in the node-major local layout (u, v, w, θx, θy, ψ)×4 BEFORE condensation of the internal modes, and fb (4: bubble x, y, incompatible 1, 2).

Asap.shell_resultants_local — Function
shell_resultants_local(section, xy, a24, fb; at = (0.0, 0.0)) -> NamedTuple

Stress resultants at natural point at from LOCAL nodal displacements a24 (node-major (u, v, w, θx, θy, ψ)×4) and the internal-mode load fb:

  • N = (Nxx, Nyy, Nxy) [force/length] — membrane forces, tension positive
  • M = (Mxx, Myy, Mxy) [force] — moments per unit length; positive Mxx puts the +e₃ face in tension along e₁
  • Q = (Qx, Qy) [force/length] — transverse shears (MITC4 field)

The membrane's condensed modes are recovered as α = K_bb⁻¹ (f_b − K_ba a) so N is the field the stiffness integrated.
